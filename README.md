## 🚀 About TwinMind AI

**TwinMind AI** is an intelligent career and learning platform designed to help students, beginners, and professionals make smarter decisions about their future.

In today's digital world, people learn from multiple platforms but often struggle to understand what skills they need, what to learn next, and how to achieve their career goals.

TwinMind AI addresses this challenge by creating an intelligent digital career companion that analyzes user profiles, identifies skill gaps, provides personalized learning direction, and helps users move closer to their dream careers.

**One platform. One intelligent companion. A smarter path to your future.**

## 💻 Getting Started

Follow these steps to run TwinMind AI locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd TwinMindAI
```

### 3. Frontend Setup

```bash
npm install
npm run dev
```

### 4. Backend Setup

Open another terminal:

```bash
cd backend
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start FastAPI:

```bash
uvicorn main:app --reload
```

*Adjust directory names and startup commands to match your repository structure.*
